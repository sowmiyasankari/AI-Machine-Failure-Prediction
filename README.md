
# AI-Based Industrial Machine Failure Prediction

## Project Overview
This project uses Machine Learning to predict industrial machine failure based on sensor readings.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Classifier
- Streamlit

## Input Parameters
- Temperature (°C)
- Vibration (g)
- Motor Speed (RPM)
- Pressure (bar)

## Features
- Machine failure prediction
- Normal and failure-risk classification
- Failure probability display
- Interactive Streamlit dashboard

## Model Performance
Accuracy: 99% on a synthetic test dataset.

Note: This result is based on simulated data and does not represent validation on real industrial machines.

## How to Run

Install dependencies:

pip install -r requirements.txt

Train the model:

python train_model.py

Run the dashboard:

streamlit run app.py
